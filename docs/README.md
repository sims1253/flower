# Documentation

## [`training-speedups.md`](training-speedups.md)
Roadmap for the next iteration of speed/efficiency work. **The live work plan.**

## [`sweeps/`](sweeps/)
Per-sweep write-ups: one or two markdown files per sweep containing the plan
and (where complete) the results. Numbered to match the sweep, e.g.
`SWEEP10_PLAN.md`, `SWEEP10_RESULTS.md`. `SWEEP_RESEARCH_BRIEF.md` is the
umbrella framing document that ties the sweep program together.

## [`research/`](research/)
Background research notes (literature surveys and technique deep-dives) that
motivate the experiments, including the two KV-cache-compaction research notes
underpinning the "Still" compactor line of work.
